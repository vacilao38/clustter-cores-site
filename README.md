# Clustter cores

Vitrine pública de ferramentas selecionadas. Catálogo: Folk 1.0.0, Lake 1.2.0 e Chain 1.0.0. Código de Chain e Noon público por autorização de 23/10/2026; Folk e Lake mantêm repositórios privados. Visibilidades e continuidade em ../clustter-main/projects.json. Publicar código não autoriza novos produtos ou downloads na vitrine.

Site estático em `dist/`, sem dependências de build. Layout responsivo, apresentações CSS originais de voz e animação, filtros por plataforma e apresentações de produto com downloads. As animações são demonstrações visuais, não vídeos capturados dos aplicativos. Capturas de interface reais acompanham as descrições.

Respeita movimento reduzido e oferece pausa manual. Não há compra, cadastro ou coleta de dados. Downloads são hospedados separadamente no GitHub Releases. Para incluir produtos, altere explicitamente `catalog.json`, a apresentação e os links correspondentes; outros diretórios deste workspace nunca são publicados automaticamente.

## Publicação

Novas aplicações só devem ser publicadas na Clustter cores quando o usuário pedir explicitamente a publicação daquela aplicação. Desenvolver, compilar ou enviar código para um repositório não autoriza a publicação. Folk e Lake são as aplicações atualmente selecionadas. A regra do workspace está em `../AGENTS.md`.
